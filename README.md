# Customer Segmentation Project

## Overview

This project performs customer segmentation using K-Means Clustering based on customer demographics and spending behavior.

## Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-Learn
* VS Code

## Dataset Features

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Elbow Method
5. K-Means Clustering
6. Customer Segment Analysis
7. Business Insights

## Output Files

* age_distribution.png
* income_vs_spending.png
* customer_segments.png
* elbow_method.png
* customer_segment_summary.csv

## Results

The project successfully segmented customers into four groups and generated business insights based on spending behavior and income levels.
